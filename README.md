# Bookmark Landing Page

A landing page built with React and SCSS.

This project was created to practice frontend development and working with React components.

## Technologies

- React
- JavaScript
- SCSS
- HTML
- Vite

## Installation

To run the project locally:

```bash
git clone https://github.com/deevAP/bookmark-landing.page.git
cd bookmark-landing.page
npm install
npm run dev
```
